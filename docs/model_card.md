# Model card - FlightOps ML failure classifier

## Intended use
Demonstrate a risk-based prioritisation of machine inspections from operating conditions, and demonstrate MLOps practice (tracking, governance, serving, monitoring). **Not** intended to make real maintenance or safety decisions.

## Dataset provenance
AI4I 2020 Predictive Maintenance Dataset (10,000 rows). **It is synthetic**: generated by the dataset authors with rules for five failure modes, not collected from a running factory. ~3.4 % of rows are failures.

## Inputs
Type (L/M/H), air temperature [K], process temperature [K], rotational speed [rpm], torque [Nm], tool wear [min]. Engineered: temperature difference, mechanical power, wear x torque (justifications in `features/engineering.py`).
**Excluded:** UDI, Product ID and the failure-mode columns TWF/HDF/PWF/OSF/RNF (target leakage).

## Output
Probability that `Machine failure = 1` for the *given operating condition*, a decision at a validation-chosen threshold, and a project-defined risk band (LOW/MEDIUM/HIGH/CRITICAL; not an industry standard).
The model does **not** predict time-to-failure and does not forecast failures hours or days ahead.

## Evaluation protocol
Stratified 70/10/20 split (fixed seed). Preprocessing fitted on train only. Hyper-parameters tuned with stratified CV inside train. Thresholds selected on validation. Test set scored once per model for the final report. Metrics: precision, recall, F1, PR-AUC, ROC-AUC, Brier, confusion matrix, calibration. Selection by validation PR-AUC. Reported numbers live in MLflow and `reports/evaluations/latest_summary.json` - none are quoted here on purpose.

## Known limitations
* Synthetic data: failure mechanisms are simple rules; the engineered features mirror them, so high scores reflect the generator, not real equipment.
* Only ~340 positives in total: metrics have wide uncertainty; small test-set differences between models are not significant.
* Single-snapshot features: no history, no sensor noise, no drift in the original data.
* Risk bands and the illustrative cost ratio (FN = 10 x FP) are placeholders to be replaced with real economics.
* Production performance is **not established**.

## Risks
Over-trust of scores on synthetic data; threshold misuse (a recall-oriented threshold floods inspections with false positives); covariate drift not equal to degradation - see monitoring docs; cloudpickle model files must come only from the trusted registry.
